# BareRuby

BareRuby is an ahead-of-time Ruby compiler and toolchain for microcontrollers.

## Gems in this repository

| Gem | Role |
| --- | --- |
| [`bareruby`](gems/bareruby) | The user-facing entry point of BareRuby and the stages that run after compilation. |
| [`bareruby-compiler`](gems/bareruby-compiler) | Language processing and code generation for BareRuby. |

## Status

Version 0.1.0 carries the names and the distribution skeletons only. It implements no functionality.

## Requirements

Ruby 4.0 or later.
