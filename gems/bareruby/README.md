# bareruby

The BareRuby entry point, post-compilation stages, and host binding, machine, and adapters.

## Status

Version 0.1.0 carries the name and the distribution skeleton only. It implements no functionality.

## Installation

```sh
gem install bareruby
```

## Requirements

Ruby 4.0 or later.
